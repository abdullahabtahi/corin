## 1. Architectural Axioms & Core Principles

### Principle 1: Clinical Deterministic Safety Invariant Priority
* **Rule:** No generative AI model possesses autonomous prescribing or therapeutic authority.
* **Invariant:** Every therapeutic proposal generated by LLM reasoning must pass through a pure-function, non-probabilistic CDSS Safety Guardian engine evaluated in $<2\text{ms}$ before display to a clinician.
* **Hard Veto Conditions:**
  - Serum Potassium ($K^+$) $\ge 5.2\text{ mEq/L}$ unconditionally blocks loop diuretic escalation and MRA initiation.
  - Systolic Blood Pressure ($\text{SBP}$) $< 95\text{ mmHg}$ unconditionally triggers a perfusion veto.
  - Acute $\Delta \text{eGFR} \ge 30\%$ decline blocks escalation without attending specialist nephrology consult.
  - Lab recency $> 14\text{ days}$ mandates fresh BMP draw before titration commitment.

### Principle 2: Data Strategy & Zero State Drift (QuantumBlack Tri-Store Pattern)
* **Rule:** "Without a good data strategy, there is no AI strategy." Large language models must never compute moving averages, calculate rolling statistical z-scores, or parse unflattened 40,000-token FHIR JSON trees in prompts.
* **Implementation:**
  - Columnar analytical processing runs in-process via **DuckDB SQL-on-FHIR v2** with **Pandera** data contracts.
  - 14-day telemetry smoothing enforces Exponentially Weighted Moving Average (EWMA) with $\alpha = 0.28$:
    $$S_t = 0.28 \cdot Y_t + 0.72 \cdot S_{t-1}$$
  - Dual-vector signal fusion: 48h weight velocity $\ge +3.0\text{ lbs}$ ($Z \ge +2.0\sigma$) correlated with autonomic resting HR drift $\ge +10\text{ bpm}$ yields $88\%$ PPV for impending hospitalization.
  - Relational feature store (DuckDB), Knowledge Graph (NetworkX Cardiorenal Ontology), and Agent Feature Snapshot synchronize under an atomic SHA-256 state transaction to prevent prompt drift.

### Principle 3: "Luminous Tactile Calm" Visual & UX Craft Floor
* **Rule:** Replace legacy flat spreadsheet EHRs and flashing neon mission-control dark cockpits with a tactile, luminous porcelain workstation designed for 45-second clinical cognitive triage under daylight fluorescent task lighting ($4,000\text{--}5,000\text{ K}$).
* **Craft Floor Invariants:**
  - **No Pure White Blinding Glare:** Interactive surfaces must never use stark `#FFFFFF`. Workstation uses porcelain 3-tier layering: Studio Canvas (`#EAEFF5`), Container Section (`#EDF1F6`), Elevated Tile (`#F4F6FA`).
  - **Specular Rim Physics:** Silicate chamfered rim borders with `1px solid rgba(255, 255, 255, 0.95)` and inset bevel highlight (`box-shadow: inset 0 1px 1px 0 #FFFFFF`).
  - **Absolute Ban on Kickers / Eyebrows:** Eyebrow labels floating above headings are strictly banned. Headings must carry their own typographical weight.
  - **Continuous Calipers over Binary Badges:** Continuous pastel spectrum tracks with 2.5px dark slate caliper needles replace discrete green/red status pills.
  - **Mandatory Tabular Numerals:** All vitals, labs, timestamps, and dosages enforce `font-variant-numeric: tabular-nums`.

### Principle 4: Abridge Linked Evidence & ONC HTI-1 Algorithm Transparency
* **Rule:** Every clinical assertion presented to the attending physician must be an interactive anchor linked directly to raw, verifiable evidentiary lineage.
* **The 5 Immutable Grounding Tiers:**
  1. `[1]` Clinical Practice Guideline (ACC/AHA/HFSA 2022 §7.3.1 Class I Recommendation, LOE B-NR).
  2. `[2]` IoT Scale Telemetry Packet (Cellular Cat-M1 scale CS-88219, DuckDB EWMA $\alpha=0.28$, $Z=+2.41\sigma$, $p=0.008$).
  3. `[3]` Autonomic Sensor Telemetry (Optical PPG resting HR drift $+14\text{ bpm}$, 72h nocturnal shift).
  4. `[4]` EHR Laboratory Observation (FHIR Observation LOINC 2823-3 $K^+ 4.6\text{ mEq/L}$, LOINC 33914-3 eGFR $54\text{ mL/min}$).
  5. `[5]` Patient Telehealth Voice (Twilio Conversational SMS transcript, 2-pillow orthopnea report).
* **Bi-directional Spotlight Coupling:** Interacting with evidence chips simultaneously highlights affected organ parenchyma on the 3D twin and spotlights corresponding telemetry cards on the dashboard.

### Principle 5: Zero-Modal Prescribing Ceremony & FHIR Interoperability
* **Rule:** Eliminate modal dialogs that disrupt provider workflow and cause $49\%\text{--}96\%$ alert override rates.
* **Order Ceremony:**
  - Prescribing proposals and safety gates are embedded inline adjacent to supporting evidence.
  - 3-State Morphing 1-Click Action:
    1. *Verified Draft State:* Deterministic CDSS Invariant Cleared ($1.8\text{ms}$). Attending Dr. Robert Chen, MD (NPI 1948201948).
    2. *Signing Transition:* Micro-pulse cryptographic state commit ($280\text{ms}$).
    3. *Committed State:* Permanent immutable audit card displaying cryptographic Action Intent Token (`act_corp_94021_loop80`), HL7 FHIR `MedicationRequest` (#medrx-88319) dispatched to Walgreens #4402, HL7 FHIR `ServiceRequest` (#serv-29401) for STAT Day 3 Fasting BMP, and automated Twilio SMS dispatch to patient.

### Principle 6: Asynchronous Multi-Agent Strands Mesh Architecture
* **Rule:** Distribute intelligence across specialized, cost-and-latency-optimized models governed by AWS Strands SDK:
  - System 1 Decider Gate: Amazon Nova Micro ($<5\text{ms}$ triage).
  - Conversational Health Coach: Amazon Nova Micro ($334\text{ms}$ SMS dialogue).
  - Clinical Expert Agent: Anthropic Claude Sonnet 4.6 on Amazon Bedrock ($1,420\text{ms}$ SBAR synthesis).
  - Guideline Reranker: Cohere Rerank 3.5 on Bedrock ($320\text{ms}$ cross-encoder precision).
  - End-to-end swarm execution target: $<3.0\text{s}$ total latency.

## 2. Frontend-Backend Contract Alignment

The frontend TypeScript layer (`frontend/src/types/clinical.ts`, `frontend/src/lib/api.ts`, `frontend/src/context/ClinicalContext.tsx`) is designed to mirror the backend Python/FastAPI/DuckDB schema without modifications:

```
[ DuckDB / Synthea FHIR ] ───> [ FastAPI Pydantic V2 ] ───> [ frontend/src/types/clinical.ts ]
   - LOINC 2823-3 (K+)            - PatientClinicalSnapshot     - PatientClinicalSnapshot
   - LOINC 33914-3 (eGFR)          - BiometricTrajectory         - BiometricTrajectory (14d points)
   - RxNorm 4603 (Lasix)          - CdssSafetyVerdict           - CdssSafetyVerdict
   - RxNorm 24323-8 (BMP)         - FhirMedicationRequest       - FhirMedicationRequest (#medrx-88319)
   - Twilio Webhook (SMS)         - ProvenanceCitation          - ProvenanceCitation ([1]-[5])
```
