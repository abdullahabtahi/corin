# 04. UX & Interaction Design

This directory contains the user experience specifications, clinical design system tokens, wireframe blueprints, and heuristic audits for **Corin**.

---

## Documents

1. [**Corin UX Architecture & Wireframe Blueprints**](./corin_ux_system_and_artifacts.md)
   * **Multi-Actor Information Architecture:**
     - Screen 1: Zero-App Conversational SMS Patient Dialogue (Natural Language Experience - NLX).
     - Screen 2: ACO Care Manager Population Triage & Risk Worklist.
     - Screen 3: Physician 45-Second 1-Click SBAR Action Card.
     - Screen 4: Hackathon & Investor "Multi-Agent Theater" (Live Demo Mode).
   * **AI-Native Agency-Control Matrix:** Strict boundaries between automated telemetry filtering, conversational discovery, deterministic safety gating, and 100% human-authorized prescription signing.
   * **Clinical Design System (CDS v1.0):** WCAG 2.2 AAA color tokens (`--color-safety-emerald`, `--color-critical-crimson`, `--color-clinical-navy`), monospaced tabular typography, and accessible 48px touch targets.
   * **Nielsen's 10 Usability Heuristics Audit:** Evaluated specifically for clinical safety, alert fatigue reduction, and cognitive ergonomics in high-stress medical environments.
