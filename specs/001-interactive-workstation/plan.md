## Summary

Overhaul Project Corin from a static presentation dashboard into a top 0.01% interactive, fluid, tactile cardiorenal digital twin workstation. 
Key implementation vectors:
1. **Living Bio-Rhythmic Twin (`TwinCanvas.tsx`):** 82 bpm ($731\text{ms}$) pulsatile cardiac/pulmonary hemodynamic cycles, toggleable multi-layer anatomical inspection modes (Vascular Congestion, Pulmonary Fluid Stasis, Renal Invariants), and interactive leader-line callout physics.
2. **Interactive 14-Day Time-Travel Scrubber (`TimeScrubber.tsx`):** Liquid glass timeline docked in the viewport that scrubs from Day -14 to Day 0, interpolating vitals, calipers, and organ strain indicators in real time at 60fps with animated Play/Pause playback controls.
3. **Tactile Calipers & Metric Probing (`BiomarkerCalipers.tsx`):** Direct caliper needle dragging/probing to simulate threshold boundary breaches with live telemetry tooltips.
4. **Backend Sync Contract Integrity (`clinical.ts`, `api.ts`, `guardian.py`):** Ensuring telemetry keyframes, FHIR orders, and Strands agent trace structures cleanly map to the upcoming Python/DuckDB backend.

## Phase 0: Research & Decision Log (`research.md`)

1. **Rhythm Pulse Mechanics:**
   - Use CSS `@keyframes hemodynamic-pulse` with `animation-duration: calc(60s / var(--resting-hr, 82))`.
   - Modulate transform scale between `1.0` and `1.035` on the cardiac bed, and stroke opacity on pulmonary vessels.
2. **Timeline Interpolation Math:**
   - 14 distinct daily samples mapped from `Day -14` (stable) to `Day 0` (current decompensation).
   - Linear interpolation ($LERP$) for intra-day scrubbing:
     $$V(t) = V_a + (t - a) \frac{V_b - V_a}{b - a}$$
3. **Anatomical Shader Layers:**
   - CSS filter presets (`filter: saturate(...) drop-shadow(...)`) + SVG mask highlights for:
     - `Vascular Congestion`: Highlights pulmonary veins and vena cava in pulsating cyan/amber.
     - `Pulmonary Fluid Stasis`: Highlights bilateral lung bases in transudative gold.
     - `Renal Invariants`: Highlights retroperitoneal kidneys in emerald shield glow.
     - `Full Synthesis`: Combines all three with active hemodynamic focus.
